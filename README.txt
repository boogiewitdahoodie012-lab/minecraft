GET YOUR .JAR (easiest, no setup):
1. Make a free GitHub account, create a new empty repo, upload everything in this folder (including the hidden .github folder).
2. Open the repo's Actions tab, wait for "build" to go green, open the run, download the AuroraTunes-jar artifact.
3. Put the jar (not the -sources one) in your mods folder along with Fabric API.

OR locally: install Java 25 + Gradle, run "gradle build" in this folder, jar is in build/libs.
